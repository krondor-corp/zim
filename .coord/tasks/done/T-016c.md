## Goal
Owner-side daemon surface for managing the `manifest.mirrors` field added by T-016a. See T-016 `## Proposal (20260524T044750Z thing5)`.

## Acceptance
- [ ] CLI: `zim bucket mirror add <bucket_id> <peer_pubkey>`, `zim bucket mirror remove <bucket_id> <peer_pubkey>`, `zim bucket mirror list <bucket_id>`.
- [ ] HTTP: `POST /buckets/{id}/mirrors` (add), `DELETE /buckets/{id}/mirrors/{pubkey}` (remove), `GET /buckets/{id}/mirrors` (list).
- [ ] Owner-membership required for add/remove; list is owner-only too (mirrors are private metadata for the owner's deploy).
- [ ] `cargo build/test/clippy/fmt` all green.

## Out of scope
- zim-fs schema (T-016a).
- zim-protocol gating (T-016b).
- zim-hub deploy UX (T-016d).
