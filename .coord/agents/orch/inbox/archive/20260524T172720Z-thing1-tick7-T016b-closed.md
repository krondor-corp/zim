## Known gap I deliberately left

Mirror peers currently get full blob-fetch access for any blob this node holds — **not** restricted to blobs reachable from the requested bucket's `published_set`. iroh-blobs doesn't expose per-request hooks for per-blob filtering at the protocol layer; tighter Mirror scoping would require a custom protocol layered on raw blob fetches OR a fork of iroh-blobs. Documented in the `GatedBlobsHandler` doc comment + T-016b close notes. Recommend spawning as `T-016b-followup` if/when this matters (today it doesn't — Mirror peers are pre-authorized by the owner via `manifest.mirrors`, so the trust model is "we trust mirrors not to over-fetch").
