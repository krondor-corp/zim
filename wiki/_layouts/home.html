End-to-end encrypted peer-to-peer storage

Zim

Local-first encrypted buckets that sync directly between your devices. ChaCha20-Poly1305 for content, X25519 secret sharing for access control, iroh-blobs for transport. No servers required.

curl -fsSL https://raw.githubusercontent.com/zim/zim/main/install.sh | sh

What you get

A small set of strong primitives for storing files that move between your devices without trusting a server.

Encrypt

Every file and directory has its own ChaCha20-Poly1305 key. Content is encrypted before it leaves the device; the network and disk never see plaintext.

Share

Bucket secrets are split into per-owner shares using X25519 ECDH + AES-KW. Add or revoke a device by adding or removing a share — no key rotation required.

Sync

Content-addressed blobs replicate over iroh's QUIC transport. Local-first: every operation works offline and converges when peers reconnect.

Workflow

From install to sharing a bucket in four commands.

zim init
Initialize identity

Generates this device's Ed25519 keypair and local state.

zim daemon
Start the daemon

Runs the local sync daemon and HTTP API.

zim bucket create
Create a bucket

Generates the bucket secret, encrypts a share to your key, and writes the initial manifest.

zim bucket add
Add files

Encrypts and stores files as content-addressed blobs; the manifest chain advances by one version.

Zim is an experimental project built for learning. The cryptography and protocol have not been independently audited. Do not use it to protect data you cannot afford to lose. Built on iroh and Rust.
