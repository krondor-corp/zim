## Goal
Apply the T-006 target design to `crates/common/**`: delete `PrincipalRole`, the Mirror branch in shares, the published-only mount path, and collapse `Principal` to `PublicKey` everywhere appropriate. Clean break — no compat shims.

See T-006 `## Proposal (20260524T014300Z thing2)` for the full design and per-file touchpoints.

## Acceptance
- [ ] `PrincipalRole` enum and its `Display` impl deleted.
- [ ] `Principal` struct collapsed to `PublicKey` everywhere it appears (no `role` field, no struct if redundant).
- [ ] `Share::new_mirror` / `Share::is_mirror` / `get_shares_by_role` deleted; Share always carries an encrypted secret.
- [ ] `add_mirror`, `MirrorCannotMount`, role-aware re-encrypt loop, and all role match arms in `mount_inner.rs` deleted.
- [ ] `load_mount_for_read` role match in `peer_inner.rs` deleted; published-vs-head choice becomes an explicit parameter.

- [ ] `cargo build && cargo test && cargo clippy -- -D warnings && cargo fmt -- --check` all pass.
