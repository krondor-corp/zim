How it works

End-to-end encryption

ChaCha20-Poly1305 + X25519 secret sharing

Every byte is encrypted with keys that never touch the hub. The hub stores ciphertext and routes blocks; it can't read your files.

Peer-to-peer sync

iroh-blobs over QUIC, DHT discovery

Your devices talk to each other directly when they can. The hub is a always-on relay when they can't — same ciphertext, no decryption.

Self-hostable

single static binary

One Rust binary, SQLite for app state, your data dir. Run it on a Raspberry Pi, a VPS, or a hosted service — all the same.

Browser access

zim-wasm + passphrase recovery

Recover an identity from any browser with your passphrase. The hub never sees the unwrapped key.

Getting started

install
Run the daemon

cargo install zim on any machine you want to be a peer.

sign in
Sign in to the hub

Google OAuth. First-time admins are configured in the hub's admin_emails; everyone else lands on a pending-approval page.

register
Register your daemon

Paste your daemon's pubkey (from zim id) on /app/devices — the hub joins on this to scope vaults to you.

mirror
Mirror a vault

zim vault <name> relays add hub — the hub starts mirroring ciphertext.
