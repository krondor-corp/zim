Register this browser

This page generates an ed25519 keypair locally, wraps the private key with your passphrase, and pushes the wrapped blob to the hub's escrow store. The unwrapped key stays in this browser (IndexedDB); recovery from another browser requires only the same passphrase.

What happens here

keygen
WebCrypto Ed25519

Chrome 113+, Safari 17+, Firefox 130+.

PBKDF2
Derive AES-GCM key from passphrase

SHA-256, 100 000 iterations, random 16-byte salt.

AES-GCM
Wrap the private key JWK

Random 12-byte IV. Wrong passphrase fails the AEAD check loudly.

escrow
PUT /api/v0/escrow

did:web:{{ hub_host }}:u:{{ user_id }}#browser-<rand> — hub gates writes on the u: segment.

register
POST /app/devices/add

The pubkey joins the regular user_peers table; vault access works the same as for daemons.
