## Goal
Implement the T-008 proposal in `zim-fs` and `zim-protocol`: replace `Manifest::public` (whole-bucket secret) with `Manifest::published_set: Vec<PublicEntry>`, per-node publication exposing one node's existing `NodeLink::Secret` to the manifest.

See T-008 `## Proposal (20260524T...Z thing2)` for the full design.

## Acceptance
- [ ] `Manifest::public` field deleted. New `published_set: Vec<PublicEntry>` added.
- [ ] `PublicEntry { target: Link, secret: Secret, display_path: Option<String>, mode: File|Folder }` type added.
- [ ] Per-node publish/unpublish/rotate ops implemented: `publish_file(path)`, `unpublish_file(path)`, `publish_folder(path)`, `unpublish_folder(path)`, `rotate_file(path)`, `rotate_folder(path)`.
- [ ] Auto-republish on commit wired: every owner commit re-resolves entry `display_path` against the new head, refreshes target+secret in place, prunes dangling entries.
- [ ] Rename/move/delete semantics: strict path-match (renames/moves/deletes prune).
- [ ] Schema migration delta documented (manifest format change).
- [ ] `cargo build --workspace && cargo test --workspace && cargo clippy --workspace -- -D warnings && cargo fmt --all -- --check` all green.

## Out of scope
- `zim-peer` daemon endpoints / CLI (covered by T-008b).
- Docs (covered by T-008c).
- The `track_by: ContentLink` future mode (out of scope this pass).
