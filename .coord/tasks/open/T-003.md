## Goal
Create a migration plan that de-scopes the desktop app and introduces a GitHub-like web UI direction using Datastar instead of HTMX.

Constraint update:
- Web app should achieve parity with desktop user capabilities.
- Single-user workspace UX only in this phase.

## Acceptance
- [ ] Desktop deprecation impact list is produced (code, docs, release flow).
- [ ] Datastar adoption plan is documented with integration touchpoints and no HTMX usage.
- [ ] User-facing transition narrative is drafted: desktop-first to read-only web gateway + WASM client.
- [ ] Desktop-to-zim-hub parity checklist is documented for UX and flows.

## Out of scope
- OAuth backend implementation.
- Cryptographic key server internals.
- Multitenant UX, team switching, and org administration screens.

## Notes
- Updated with factor-1 direction: remove desktop emphasis, move to web-first hub UX.
