## Template summary (krondor-corp/generic)

`wiki/` is a Jekyll-based GitHub Pages site, NOT a replacement for `docs/`. The template keeps both:

- `docs/` — repo-local reference (markdown, no Jekyll)
- `wiki/` — public docs site, deployed to `<project>.krondor.org/wiki/`

Wiki layout (relevant bits):

```
wiki/
├── Gemfile, Gemfile.lock, Makefile
├── _config.yml          # collection: docs, permalink /docs/:slug/
├── _data/nav.yml        # sidebar nav: [{title, items: [slug,...]}]
├── _docs/               # content — flat .md files, no subdirs
│   └── <slug>.md        # frontmatter: title, order
├── _includes/, _layouts/{default,doc,home}.html
├── assets/
└── index.md             # layout: home
```

Content conventions:
- Page frontmatter: `title:` + `order:` (integer sort within nav group)
- Permalink: `/docs/<slug>/`
- Cross-links: `{{ '/docs/<slug>/' | relative_url }}`
- Nav grouping lives in `_data/nav.yml`, not in pages
