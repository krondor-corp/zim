Set up this browser

Every account needs a browser-resident web key — it's the controlling identity that can authorize other devices to join your vaults. Mint it once here; it lives in this browser, wrapped by a passphrase you pick.

Mint a web key

WebCrypto Ed25519 · PBKDF2 + AES-GCM-256 wrap · escrow PUT

The keypair never leaves this tab. The hub stores only the wrapped (ciphertext) form; recovery from another browser needs only the same passphrase.

Start setup →

What about daemons?

Daemons enroll separately via zim login --hub — that's how the daemon proves possession of its on-disk identity key. They can already sync vaults peer-to-peer without the hub; enrolling on the hub lets the web key add them to share lists going forward.
